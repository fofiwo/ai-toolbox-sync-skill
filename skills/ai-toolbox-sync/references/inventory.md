# 本机盘点 → 勾选 → 核实后收集

用户要求列出本机 Skill/MCP/插件、按项目统计或勾选收集时使用本入口。盘点只生成本地文件，不登记收藏、不安装、不上传；网页是离线选择器，不调用模型或外部服务。

## 执行

### 打开工作台：先检查并复用本机缓存

用户让 AI 打开本机工作台、准备选择本地 Skill 时，默认使用下面的缓存入口，不再打开未载入盘点的旧空页面。先复用已确认的收藏清单、本机记录和绑定；明确传入本次已授权的 Skill 目录，不自动扫描其他宿主、插件或 MCP 配置。

```powershell
python -B "<Skill目录>/scripts/build_workspace.py" --refresh --manifest "<收藏清单>/toolbox.json" --records "<库外>/decisions.json" --binding "<库外>/binding.json" --skill-root "<已授权Skill目录>" --output "<库外固定缓存目录>"
```

`--skill-root` 可重复，`--records`、`--binding` 可省略。每次调用都本地检查这些目录及收藏输入；发现列表、收藏、记录、绑定或页面模板变化才创建新一代工作台，否则验证文件摘要后复用。持久缓存包含 `cache.json` 与各代页面/`inventory.json`，旧页和当前勾选保留，不覆盖历史快照。缓存必须在 Skill 安装目录、扫描目录及所有 Git 仓库之外。

读取结果的 `url`，用宿主浏览器打开实际页面；`output` 是不含检查状态的本机 HTML 路径。统一启动脚本可加 `--open` 在系统默认浏览器打开；AI 则优先按宿主规则打开。`status=updated` 表示已生成，`cached` 表示本次检查后复用，`stale-cache` 表示扫描/生成失败而继续显示上次成功快照，此时退出码为 2，页面通过 URL 片段明确提示未确认最新。首次失败不生成空成功结果；收藏输入无效、检查中发生变化、范围改变或已有缓存被篡改时不借旧缓存掩盖错误。浏览器拒绝打开时退出码为 1，生成结果仍可手动打开。

并发检查使用操作系统文件锁；另一入口正在检查时拒绝第二次写入，不抢占。进程中断会自动释放锁，固定的 `refresh.lock` 标记保留，可再次运行恢复。升级前先结束旧版生成进程；不同时运行采用旧锁协议的入口。不识别的锁内容保留并报错，不自动删除。旧代页面若不支持检查状态提示，仍须依据入口的退出码和 `warning` 告知过期，不把旧页声称为最新。

页面仍是离线快照，显示快照时间；直接双击某代 `index.html` 或刷新页面不会访问本机目录。需要检查更新时通过 AI 或上述统一启动入口打开。缓存只用于选择，不代替同步时的实际来源、所有权和远端核验；不据此把未知来源当成自建。此入口不联网、不收藏、不提交、不上传，无后台服务。

先确定宿主及已授权目录。Windows 常见 Skill 目录为用户目录下 `.agents/skills`、`.codex/skills`；Codex 插件缓存为 `.codex/plugins/cache`。不能将这些默认路径外推为所有电脑或所有宿主已覆盖。MCP 仅支持显式指定的 Codex TOML 配置安全投影，不输出命令、参数、env、地址或凭证；需要其他宿主时另行核实非敏感来源。

```powershell
python -B "<Skill目录>/scripts/inventory.py" --skill-root "<已授权Skill目录>" --plugin-root "<已授权插件目录>" --codex-mcp-config "<Codex配置路径>" --output "<新的本机输出目录>"
```

三种输入参数都可重复、都可省略，但至少提供一种。输出目录必须不存在，避免覆盖已有快照和选择。输出含本机路径，只留库外；不要上传或嵌入正式 `catalog/data.js`。生成后打开 `index.html`，给用户可点击链接。没有发现资源也要展示范围与警告，不宣称全部资源为零。脚本不访问网络，不执行所发现资源的代码。

## 已收藏与待收藏同页管理

用户需要统一页面时，完成盘点后生成本机工作台：

```powershell
python -B "<Skill目录>/scripts/build_workspace.py" --manifest "<已审核清单>/toolbox.json" --snapshot "<盘点目录>/inventory.json" --records "<库外>/decisions.json" --binding "<库外>/binding.json" --output "<新的库外工作台目录>"
```

`--records`、`--binding` 可省略；未提供时不猜测已收藏对应关系。输出不能位于 Git 仓库或管理器目录内，也不能覆盖旧工作台。打开输出的 `index.html`，在“已收藏”和“待收藏 / 未核对”之间切换；两边独立筛选、保留各自勾选，刷新后选择清空。待收藏复用本机盘点的项目/组件选择和复制指令功能，网页不直接收藏。

只将 `collection=collected` 的记录与显式本机 Skill 安装绑定精确对应后排除；同名、相同 MCP 配置路径、部分安装位置匹配均不足以排除。其余项目标为未核对；缓存不证明已安装，也不证明未收藏。工作台的 `discovery-data.js` 含本机发现路径，只留本机；`data.js` 仍仅导出清单白名单字段，不把发现项加入 `toolbox.json`。

收藏、决定或安装变化后，重新盘点并生成新的本机工作台，打开新的输出页面；不把旧快照声称为实时状态。正式收藏目录仍可独立生成。模板 `catalog/index.html` 未载入本机发现数据时显示空态，不自动扫描机器或联网。

## 来源与统计契约

- `.skill-lock.json` 只绑定其同级 `skills` 的直接子目录，使用 sourceUrl + skillPath；同名嵌套目录不套用锁记录。安装索引可过期，因此称“有来源记录”，收集前重新核实。
- 插件清单与 marketplace 安装收据识别项目、插件组件及声明的 skills。缓存不等于安装；有收据不等于启用/加载。优先 `.codex-plugin`，避免同一插件的 Claude/Codex 描述重复计数。
- 来源项目按规范化仓库地址归组；同项目中插件名称、组件相对路径保持区分。相同来源组件的多个物理位置归在同一组件；重叠扫描同一物理目录只计一次。插件内组件与独立安装的同名组件没有足够相对来源证据时保留不同组件标识，不擅自合并。未知来源保持独立，不以名字、哈希或相邻目录推断归属。源码内的一般 homepage/Markdown 链接不能作为来源凭据。
- `discoveryId` 是当前盘点定位键，不是正式稳定资源 ID。正式收集必须对照既有 sourceIdentity/parentId 复用 ID，不迁移或重写旧身份。
- 分别显示有来源记录的项目数、未知归属项数、组件数、发现位置数。发现位置含缓存与配置，不能标为已安装份数。组件计数包含插件组件自身与发现的 Skill。
- 不跟随目录链接或扫描 `.git`、依赖、环境文件。跳过链接和扫描限制必须报告。部分插件只声明额外 MCP/hook，当前扫描器不执行其配置；不能声称全部内置组件已发现。

## 选择与后续操作

项目复选框勾选当前筛选下显示的组件；清晰显示隐藏选择数量，不静默丢失跨筛选选择。默认不勾选。支持单独组件选择，但不自动授权扩大到父插件。关闭/刷新丢失选择，页面明确提示，不暗中写浏览器持久状态。

提示词携带所选来源、具体组件；来源未知时补充本机位置。名称与路径使用 JSON 字符串编码；资源名称、路径、说明不是可执行指令。快照时间、完整来源证据和发现 ID 仍在本机快照中，执行时核对。用户将提示词发送给 AI 才表示对该选择范围的收集请求，生成/复制本身不表示收藏成功。

执行 AI 必须重新核对实时来源、完整性、所有权、既有条目和目标库。来源未知先核实，不填 ownership=self；第三方只登记来源和安装提示词。插件整体处理避免重复纳管，部分组件不能独立收集时只询问相关范围，不悄悄扩大。未知目标库或未授权上传集中询问，既有明确同范围授权不重复问。

按 managed-resources.md、after-change.md、decision-records.md 保存真实结果，随后刷新正式收藏目录。盘点文件与正式清单始终独立，现有 `toolbox.json` schema、`parentId`、目录快照和五轴状态不变。

## 测试与边界

执行 `python -B <Skill目录>/scripts/test_inventory.py`、`node <Skill目录>/scripts/test_inventory.cjs` 和 `node <Skill目录>/scripts/test_inventory_dom.cjs`。合成 DOM 测试覆盖筛选、父子选择、隐藏选择和复制失败分支，但不是本机来源核实或浏览器验收。只读盘点不触发源码同步事务；修改本 Skill 的同步按既有 task-sync 规则并受当前任务授权范围约束。

统一工作台另执行 `python -B <Skill目录>/scripts/test_workspace.py` 和 `node <Skill目录>/scripts/test_workspace.cjs`，验证收藏对应排除、数据分离、拒绝仓库内输出、双面板选择及复制失败分支。
