# 同步前检查

适用于收集、Git 提交/拉取/合并/推送、资源安装/更新/恢复。AI 按 [原生 Git 工作流](git-workflow.md) 执行；本项目没有无人值守执行器，dry-run 和脚本成功不能代替差异、授权与实际结果审查。

修改前实时比较实际安装、受管源和远端，结合可信基线判断；有差异先说明双方变化和覆盖影响，用户选择后执行。仅收集不上传，只有用户本次明确请求同步才 commit/push。管理器自身走 [自维护](self-maintenance.md)，不加入私人收藏。

## 必须核实的范围

1. 从已知库外绑定定位实际 Git 根、分支、origin 的全部读取/推送 URL、资源映射与 journal。核对本机 Git/Python，GitHub 接入核对 gh 身份及真实 Git 权限。不读取凭证、完整敏感宿主配置，不重设 HOME/CODEX_HOME 或全局 Git 配置。
2. 取得 task-sync.md 的合作式仓库锁，检查 pending/workItems 和原任务状态。所有目标来自明确资源映射；Git 取得源码不顺带分发、启用插件、写 MCP 配置或扫描其他宿主。独立目录使用 reviewed-files 的逐文件审核应用；既有顶层链接须核对已批准 expected_root，嵌套链接、路径逃逸或未知目标停止。
3. 审查 tracked/untracked/ignored 文件、暂存区及全部待发送提交。只允许选定的自建源码、获准 Agent 文档快照、第三方安装索引及必要管理文件。拒绝 .env*、凭证、机器绑定、安装缓存、嵌套 Git、未经审查的可执行 hook/filter。未知文件先停，不读取敏感内容、不用忽略规则隐藏已进入历史的内容。完整性脚本对账所有应保存文件与具体提交树，被忽略的新文件也不能遗漏。
4. fetch 只取得比较对象。记录远端 SHA 和共同祖先，比较祖先至本地（含未提交变化）及远端的新增/修改/删除。清单、metadata、同文件双边修改、删除/重命名和身份冲突均先审查，不按 installed_at、时间戳或版本号自动择一。未知历史或无共同祖先先停。远端、文件、配置或授权变化使原检查失效。
5. 所有删除/重命名、目标取消、MCP 字段移除及插件卸载均单列范围并取得授权。备份仅针对缺少其他可恢复副本且将被替换的本机内容，保存在库外；不清理用户既有备份或垃圾箱。文件对比与实际应用之间仍有外部写者竞态，应用前复核摘要。

## 操作与检查对应

| 操作 | 核实内容 |
|---|---|
| fetch/ls-remote | 已授权确切 URL、分支与网络；不更新安装目录 |
| commit | 整个暂存树只能含获准变化；精确逐文件 add，不自动纳入其他修改 |
| merge --ff-only / 用户选择的普通合并 | 审核入站全仓变化及实际关联资源，工作区安全；宿主应用单独核实 |
| push 固定 SHA | 全部待发送历史及文件、实时 remote tip、非强制精确 refspec，不隐式提交/安装 |
| 收集/恢复 | 仅绑定的资源和批准文件；安装/源/基线逐文件核对，删除另授权 |
| MCP/插件注册与依赖安装 | 已选资源官方命令、非敏感字段、实际宿主和版本；本机配置不从库复制 |

已授权收藏同步由 [执行入口](task-sync.md#收藏同步执行入口) 固化检查、合并计划、精确提交、提交覆盖与实时远端核验。历史低层事务继续使用 intent/resolve 恢复，不能两套流程并行写同一仓库。兼容变化通过检查后继续；真实冲突保留现场，不能自动 reset、rebase、强推或更换远端。公开管理器发布仍只能使用 release.py push。

## 新电脑、资源归属与 Agent 文档

在新目录取得仓库，先列清单让用户选，再比较宿主已有内容；不接管旧目录、不自动全量恢复。机器路径、凭证、登录和信任在本机配置。恢复旧版本采用正常 Git 历史形成新提交，不改写历史；源恢复不意味着宿主已应用。

自建源码仅处理清单 ownership=self 且实际已授权资源。第三方与未知归属不进入源码绑定；第三方索引可随获准清单保存，本体从官方来源安装，走 [第三方更新](third-party-updates.md)。授权来自当前用户，不能继承发布者权限。

`kind=agent-document` 使用 [独立全文身份及绑定](agent-documents.md) 和 `agent_documents.py`，共享快照位于 `agent-documents/<documentId>.json`，不作为 Skill/MCP 分发。复用仓库锁和原 sync_session observation；正文摘要与完整快照摘要分开。文档已加载的会话不宣称重载；换机默认派生身份，不复制旧机器绑定。
